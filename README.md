# WearOS Serpent

**Snake Classic** for **Wear OS** watches: the classic snake game, rewritten in Kotlin
and Jetpack Compose for Wear. Steer with the arrows in the corners of the round screen
(or swipe), eat the pellet, grow, and try not to bite yourself or the wall. Everything
runs on the watch: no phone, no network, no account.

This is a port of [AmazfitSerpent](https://github.com/dchernykh1984/AmazfitSerpent),
the same game as a Zepp OS mini app. The rules, the pacing, the layout proportions and
the eleven translations are carried over unchanged; the implementation is new.

Built and tested against a **OnePlus Watch 2R** (466x466 round, Wear OS 5).
